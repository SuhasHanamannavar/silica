The Design Journey

01 / WORKFLOW
01
Frontend

Specification

Architecture, performance targets, power budget, and die-area envelope defined. The contract every downstream stage is measured against.

02
Frontend

RTL Design

Behavioral description in hardware-description language — registers, datapaths, and finite state machines captured as synthesizable logic.

03
Frontend

Functional Verification

Verilator C++ testbenches, assertions, and coverage closure prove the RTL does what the specification requires, before a single gate is placed.

04
Frontend

Logic Synthesis

Yosys logic synthesis mapping RTL to standard cell technology library. Gates sized for timing, area, and cell count.

05
Backend

Floorplanning

Macro blocks, I/O rings, and power domains arranged on the die. The skeleton on which every later stage is built.

06
Backend

Placement

Standard cells positioned legal-row by legal-row, optimized for wirelength, timing, and routability across the core area.

07
Backend

Routing

Metal interconnect drawn across stacked layers — signals, clock tree, and power grid connected without design-rule violation.

08
Signoff

Timing Analysis

Static timing closure across all process, voltage, and temperature corners. Setup and hold margins verified before signoff.

09
Signoff

Physical Verification

Design-rule check (DRC), layout-versus-schematic (LVS), and antenna checks confirm the drawn geometry is manufacturable.

10
Signoff

Tapeout Preparation

Final GDSII/OASIS database, signoff reports, and fabrication handoff package assembled for external foundry manufacture.
